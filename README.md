# Photographic Memory Trainer

A web app that tests your memory strength and helps you train it.

## How it works

1. **Take the assessment** - six tests covering pattern recall, number sequences, spatial position, color order, detail scanning, and visual associations.
2. **Get your training plan** - the app automatically builds a six-drill sequence targeting your three weakest areas.
3. **Level up** - every perfect drill attempt raises the difficulty.

## Run it

Open `index.html` in a browser, or visit the live site via GitHub Pages.
